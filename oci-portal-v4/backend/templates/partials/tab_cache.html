About Cache Clearing
  • Clears JDE JDBJ (database) caches across all configured instances
  • Also clears AIS (application integration services) data caches
  • Operation is non-disruptive to running JDE processes
  • Requires Operator or Admin role
  • All cache clearing operations are logged for audit compliance
⚠️ Important: Clearing cache will temporarily affect all JDE instances in the selected environment. This operation clears both database caches (JDBJ) and data caches (AIS) across all configured instances. Use with caution during production hours.
